# Sales Forecasting & Business Insights Dashboard

A professional data analytics dashboard built using Python and Streamlit.

## Features
- Sales Forecasting
- KPI Dashboard
- SQL Analysis
- Business Recommendations
- Interactive Charts
- CSV Upload

## Technologies Used
- Python
- Streamlit
- pandas
- numpy
- plotly
- matplotlib
- sqlite3
- scikit-learn

## Run Project

```bash
streamlit run app.py
